PHOTOS — 13 independent photo slots
-----------------------------------
Put your photos inside the "photos" folder with these exact names.
Each slot is independent — replace any one without touching the others.

Recommended: portrait or square photos, at least 800x800 px.
If a photo is missing, an elegant rose-gold placeholder is shown
automatically so the website never breaks while you prepare images.

MUSIC
-----
Put your background music inside the "music" folder as:
  music.mp3

A soft instrumental track is best. If the file is missing, gentle
procedural ambient music plays automatically as a fallback.


HOW TO EDIT TEXT
----------------
All captions, dates, personal notes and the final letter are in ONE place:
  src/data/story.ts

Open that file to personalize everything. No other code needs to change.
